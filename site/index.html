For agent-manager users

Your coding agents, on one desk.

Agent Desk is a local GUI over agent-manager. Every Claude Code session reads as a document. Answer a waiting agent with one click, review its diff and send notes back, and see the whole fleet at a glance, at your desk or from your phone. Every agent keeps running in tmux; closing Agent Desk stops nothing.

Install View on GitHub

Features

Everything an agent needs from you, in one place.

See the whole fleet

The overview gives every session a card: what it is doing right now, its last reply, your last prompt, context use and when it last changed. Sessions waiting on you come first, and a dot marks anything new since you last looked.

Subagents too: the Agents panel lists every subagent a conversation started, with its own live transcript.

Answer without attaching

When an agent stops on a permission prompt or a question, Agent Desk shows the question under its transcript with a button for each answer: checkboxes when it takes several, a text box for your own words, and each step of a multi-part prompt. It reads the screen again before it presses a key, and refuses if the choice changed.

Enter sends a reply, as in Claude Code, through agent-manager type; a reply is refused with a reason when it would land anywhere but the agent's prompt. While an agent works, a live row shows how long, the tokens written and the current step, with Interrupt to stop the turn.

Review the diff, send notes back

The Changes panel shows a session's git changes, uncommitted or for the whole branch. Click a line to comment; Send review hands the agent every comment as one numbered prompt.

Git runs read-only, with external diff tools, text converters, the repository's filter drivers and hooks disabled, so a repository cannot make it run commands.

History and usage

Browse every conversation on disk, not only the running ones, export any of them to Markdown, or resume one as a new agent-manager session. Usage shows tokens, agent working time and time spent waiting on you, by day, model, project and conversation.

Cost is what Claude Code reports, at list price.

Away from the desk

Check on your agents and answer a waiting one from your phone or another computer, through Tailscale or a Cloudflare Tunnel behind Cloudflare Access. Remote access is off until you turn it on at the desk, and you choose what remote devices may do: read and answer, also reply, or also start and stop sessions.

Remote devices never see your local link. The proxy vouches for who they are, Agent Desk checks that identity on every request, and only the people you list get in.

  • Search every transcript: prompts, replies, thinking and tool output.
  • Desktop app for macOS: its own window, native notifications, the "needs you" count on the dock and in the menu bar, and Control-Option-A to bring it forward.
  • Notifications when a session waits, errors or finishes, and a "needs you" count in the tab.
  • Slash commands complete as you type: Claude Code's own, your custom commands, skills and enabled plugins.
  • Snippets for replies you send often, with /name and Tab.
  • Rules that notify you or suggest a reply when a session reaches a status. You always press Send.
  • Pins and notes per conversation, kept in your browser.
  • Image paste into the composer, stored owner-only and cleaned after a week.
  • Color terminal view of any session, read-only.
  • Shell edits shown: files a command changed, with line counts and diffs.
  • Catch-up summaries of what happened while you were away, opt-in, through your own Claude Code CLI. They cost tokens.
  • Session management: start, stop, revive, archive and move sessions, with templates for new ones.

How it works

agent-manager runs the agents. Agent Desk is where you read and talk to them.

  1. 01

    Sessions stay in agent-manager

    Every agent runs in agent-manager's tmux server with your own CLI, login and config. Agent Desk reads session state from agent-manager snapshot and acts only through its commands.

  2. 02

    Transcripts become documents

    Claude Code's session files are parsed into prompts, replies, tool calls and diffs, and followed live as the agent writes. Records it does not recognize are shown, never dropped.

  3. 03

    One binary, one port

    A Go server with the React app embedded, on 127.0.0.1. Close it and every agent keeps working.

Local and safe

Your agents, your machine, nobody else.

Loopback by default

Listens on 127.0.0.1. Every request needs a token that changes on each start, and must name the server's own host; state-changing requests must come from its own origin. Remote access, off until you turn it on at the desk, arrives through an owner-only socket with an identity checked on every request.

No telemetry

No analytics, and no network calls of its own. The one exception is opt-in: with Cloudflare remote access, it fetches your team's public signing keys from Cloudflare. This page has no analytics either.

No API keys

Agent Desk never asks for a key and never calls a model API. Optional catch-up summaries, off by default, run your own Claude Code CLI only when you press the button.

Read-only transcripts

Nothing is ever written under ~/.claude. Agent Desk reads Claude Code's files and runs local CLIs, nothing more.

Install

One command with Homebrew.

You need

  • Homebrew, on macOS or Linux; it installs agent-manager and tmux with Agent Desk
  • Claude Code
$ brew install gsperry/tap/agent-desk
$ agent-desk
Agent Desk listening on http://127.0.0.1:7317

It opens in your browser. Releases have the command for each platform and the macOS desktop app, which is unsigned until the next release. To build from source (Go 1.27 and Node 24), see the README. Status: early, built and used on macOS; CI also builds and tests on Linux.
